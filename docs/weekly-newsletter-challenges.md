# Sponsor challenges in the Weekly Newsletter

Newly generated newsletter drafts include sponsor challenge announcements in the existing updates section: challenge title linked to its public award page, sponsor name, and hackathon name.

Eligibility:
- Award type is `challenge`, with a sponsoring organization.
- Award is available, unawarded, or awarded, and is not archived.
- Hackathon is public and its conference is published.
- First availability falls in the issue's seven-day lookback, capped at draft creation time to exclude future announcements. Start is inclusive; end is exclusive.

Migration 114 adds `awards.published_at`. A database trigger records first availability for both sponsor approvals and organizer-created awards. Editing or hiding/reopening an award preserves the timestamp. Existing public awards use the approved proposal's review time where available, otherwise creation time; historic organizer draft-to-public transitions cannot be reconstructed exactly.

Existing newsletter drafts keep their saved editorial copy and are not regenerated by this change. Add challenge items manually to an already-created issue if needed. The migration and application change must be deployed before newly generated production drafts use this behavior.
